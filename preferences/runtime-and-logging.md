# 本地运行、部署与日志偏好

- **默认使用场景**：大部分项目供本人在本地使用，需求和方案默认围绕本地个人使用场景设计。

- **运行与部署**：默认交付能够在本地运行的项目及必要的启动说明，允许在本地电脑上启动 Express 后端。前端和后端在两个终端中分别启动，方便分别查看日志和重启。除非当前任务明确要求，否则无需部署到远程服务器或云端。交付说明应包含实际可用的安装、启动、停止和重启步骤，以及端口、配置项、数据位置和日志位置。必要配置缺失或端口冲突时，程序应提供明确提示。涉及数据迁移或重要数据修改时，提供与风险相称的备份、迁移或恢复说明。

- **登录与权限功能**：除非当前任务明确要求，否则默认无需实现登录、注册、用户账号体系、角色或权限管理。

- **错误处理和日志**：后端运行日志默认同时输出到终端并保存到本地日志文件，方便程序重启后回看错误，以及由 Agent 分析历史问题。需控制日志文件大小，避免日志无限增长。后端统一处理未预期错误，并保持接口错误结构一致。页面显示可理解的错误原因和适用的下一步操作；详细排查信息记录在后端日志中。日志包含必要的时间、操作和错误上下文，不记录密钥等敏感信息。需要关联接口请求与后台任务时，加入对应的请求或任务标识。
