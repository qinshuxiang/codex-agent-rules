# 页面布局、数据展示与交互偏好

- **整体布局与区域功能**：应用主界面优先参考 shadcn-vue Blocks 的布局与功能组织（https://shadcn-vue.com/blocks），包括侧边导航及分组、快捷操作、顶部页面标题或路径、主内容区，以及设置、帮助、搜索等辅助入口。数据概览页面优先参考 `dashboard-01` 的“统计卡片、图表、数据表格”组织方式（https://shadcn-vue.com/view/dashboard-01）。区域和操作按实际业务需要选用，示例的业务名称、演示数据和全部菜单项不作为每个项目必须实现的需求。

- **信息组织与视觉层级**：明细数据优先使用表格和列表，概览与关键统计指标使用卡片，趋势与对比使用图表。优先沿用 shadcn-vue 官方示例中表格工具栏、视图切换、列显隐、行选择、状态标识、行操作和分页，以及图表时间范围选择等展示与交互方式；具体功能由当前需求决定。

- **登录注册页面**：项目明确需要登录或注册时，优先复用官方 Login Blocks（https://shadcn-vue.com/blocks/login）和 Signup Blocks（https://shadcn-vue.com/blocks/signup）的页面结构、表单组织和组件，再与项目整体视觉统一。认证方式由项目需求决定，示例中的第三方登录等入口按需采用。默认无需登录、注册及账号体系的规则按 [本地运行偏好](runtime-and-logging.md) 中的“登录与权限功能”条目执行。

- **操作路径与交互反馈**：涉及数据请求或提交的页面，应按实际流程提供加载、成功、空结果和失败状态。提交过程中提供明确反馈，并采取适当措施避免误操作造成重复提交。涉及批量处理时，按需区分全部成功、部分成功和全部失败。耗时操作提供适合任务的执行状态或进度反馈。
