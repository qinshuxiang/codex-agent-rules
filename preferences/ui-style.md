# 界面视觉风格偏好

- **代码风格**：前端项目 UI 组件采用 shadcn-vue，视觉风格固定为 Lyra（方正规整、棱角分明，搭配等宽字体）。预设：https://shadcn-vue.com/create?preset=a1l3HCS ；CLI 等价：`npx shadcn-vue@latest create --style lyra`。新建或初始化 Vue 前端项目时默认套用，除非当前任务明确指定其他风格。

- **整体视觉风格**：整体以指定的 shadcn-vue 预设为主（https://shadcn-vue.com/create?preset=a1l3HCS），X（原 Twitter）的网站风格仅作为辅助参考。喜欢指定预设的整体视觉风格和其中的各类组件，也喜欢 X 的整体网站风格。

- **界面密度、布局与留白**：偏好较高的信息密度，一屏尽量展示更多有用内容，同时保证文字可读、层级清楚和操作方便。布局参考 [页面布局、数据展示与交互偏好](ui-layout-and-interaction.md)。

- **默认主题**：跟随系统的浅色或深色主题。
