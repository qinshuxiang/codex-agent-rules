# 界面组件与页面复用偏好

- **组件与页面复用**：Vue 前端开发前，先检查 shadcn-vue 官方仓库是否已有对应组件或 Blocks（https://shadcn-vue.com/blocks）。本规则覆盖该仓库中所有组件，不限于对话中举例的组件。已有实现能够满足需求且兼容项目时，直接使用该仓库的实现，不自行重复开发同类组件；允许直接引入或复制官方源码，再按项目需求配置和调整。业务页面和复合组件优先通过组合官方组件实现；官方采用组件组合提供某项能力时，复用官方组合方式。组件的配色、字体、圆角、尺寸、间距和交互状态统一遵循项目主题及已确认的 Lyra 视觉风格，保持组件样式的高度一致性，避免为单个页面另写一套同类组件样式。只有官方缺少对应能力、现有实现无法满足明确需求，或存在项目兼容性限制时，才补充自定义实现，并说明原因。需要自行开发该仓库中不存在的组件或结构时，必须在开始实现前主动通知我，说明拟开发的内容、原因，以及现有官方组件或组合方式为何不能满足需求。继续遵循已有项目惯例，以及已确认的 JavaScript 和 Vue 3 偏好。
