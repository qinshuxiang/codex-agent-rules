# 技术栈与代码风格偏好

- **默认编程语言**：新建项目和编写新代码时，默认使用 JavaScript。已有项目遵循项目现有语言和规范；需要引入 TypeScript 时，说明原因。

- **前端技术栈**：默认使用 Vue 3，组件逻辑采用 Composition API，并使用 `<script setup>` 写法。

- **后端技术栈**：默认使用 Node.js + Express，业务代码使用 JavaScript。

- **编程范式**：更喜欢函数式编程，优先采用函数式编程风格。

- **通用函数封装**：允许封装通用函数，供业务代码复用。

- **代码缩进**：JavaScript 和 Vue 代码默认使用 4 个空格缩进。

- **代码注释的详细程度**：文档注释应详细充分、通俗易懂，尤其是封装的通用函数。

- **包管理器**：没有固定偏好，根据项目情况选择。

- **数据库选择**：没有固定偏好，根据项目情况选择；SQLite、MySQL、PostgreSQL、MongoDB、Redis 按需使用。
