# 接口、请求与数据偏好

- **前端请求工具**：前端调用后端接口时，默认使用 Axios，并封装统一的请求模块供业务代码复用。统一管理接口基础地址、默认超时和公共错误转换；业务接口调用按功能组织，减少在页面组件中重复拼接地址和配置请求。页面负责决定具体的加载状态、错误展示和交互反馈。

- **接口约定与说明**：前后端实现前，明确主要接口的路径、HTTP 方法、参数、请求体、成功响应、失败响应和状态码。接口使用与操作含义相符的 HTTP 方法和状态码。项目内保持响应结构和错误结构一致。小项目可以使用接口表与请求、响应示例；接口较多或需要自动生成文档、校验时，再按需采用 OpenAPI。长时间运行的接口应明确“请求已接受”与“任务已完成”的区别，并提供适合当前功能的任务状态查询或进度反馈方式。

- **输入校验与数据约定**：前端校验用于及时提示，后端对外部输入执行必要校验，并负责保证业务规则和数据有效性。项目内统一字段命名、字段类型、空值含义、时间表示和状态值。列表接口按实际数据量确定分页、筛选和排序方式，并明确默认值与允许范围。需要共同成功或失败的多步数据修改，采用适合存储方式的一致性措施。
