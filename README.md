# Codex Agent Rules

跨项目复用的中央规则包。全部规则集中在 `AGENTS.md`，不再拆分文档与偏好模块。

## 使用方法

每个新任务开始时，先读取中央规则：

```
/Users/siluhao/Downloads/ChatGPT/codex-agent-rules/AGENTS.md
```

把这一句写入任意项目的自定义指令或任务提示，使会话优先加载该文件。

跨机器或无法访问本地路径时，改用仓库地址：

```
https://raw.githubusercontent.com/qinshuxiang/codex-agent-rules/main/AGENTS.md
```

## 规则内容

`AGENTS.md` 分四部分：

| 章节 | 内容 |
| --- | --- |
| 技术栈与代码风格偏好 | 默认语言、前后端框架、数据库、目录命名、注释要求 |
| 执行原则 | 编码前先思考、简洁优先、精准修改、目标驱动与可验证执行 |
| 技术表达 | 写作要求与表达形式选择 |
| 维护边界 | 偏好的新增、修改、删除流程 |

技术栈一节是默认值，可被项目惯例、目录级规则或用户当前指令覆盖，覆盖只在冲突处生效。

## 读取时机

- 每个新任务开始时读取中央 `AGENTS.md`。
- 规则发生变化、工作范围切换或缺少相关上下文时重新读取。
- 当前上下文已读取且未变化的内容可以沿用，不重复读取。

## 设计原则

1. **执行**：怎么分析问题、实施改动、限定修改范围。
2. **表达**：借鉴 ASD-STE100 的清晰写作原则，并按理解需要选择文字、表格、图示或交互网页（不要求正式合规）。
3. **验证**：怎么证明任务完成，未执行的检查如何标注。
4. **边界**：偏好不是事实，未记录的内容不自行推定。

## 维护方式

- 规则只改 `AGENTS.md`，不另建副本或平行实现。
- 新增、修改或删除偏好前须获得明确确认，只更新指定条目。
- 提交前检查差异，确认每处改动都对应一次明确需求。
